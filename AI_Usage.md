# AI Usage Documentation

## AI Tools Used

1. **LangChain** - For building the RAG pipeline
2. **OpenRouter API** - For accessing language models
3. **ChromaDB** - For vector storage
4. **FastAPI** - For creating the API backend

## Usage Details

The application uses AI to:
- Process and embed documents
- Store document embeddings in vector database
- Retrieve relevant context based on user queries
- Generate answers using the retrieved context
